//
//                 +-----------------------+  y 1296
//                 |      DINING ROOM      |

//   | (sector 0)|---------------+  y 192
//   +-----------+
//   x 0       x 640               x 1040
//
// How UDMF works, in short:
//   vertex  = a corner point
//   linedef = a wall between two vertices. Its "front" side (sidefront) is
//             on the RIGHT when you walk from v1 to v2. Here every room is
//             traced clockwise, so the right-hand side is always inside.
//   sidedef = the texture on one side of a linedef, and which sector it's in
//   sector  = a room: floor/ceiling heights, flat textures, brightness
//   thing   = player start, items, monsters
//
// After editing, run tools\pack_map.ps1 to rebuild mod\maps\MAP01.wad.
// ===========================================================================
