// ---------------------------------------------------------------------------
// recams.txt - fixed cameras and camera switch zones, RE1 style.
//
// camera <id>  <x> <y> <z>   <lookX> <lookY> <lookZ>   <fov>
//     Where the camera sits, the point it looks at, and how wide it sees
//     (degrees). RE1's rooms use about 70-75.
//
// zone <from> <to>   <x0> <y0>  <x1> <y1>  <x2> <y2>  <x3> <y3>
//     A 4-corner area on the floor. While camera <from> is active and the
//     player stands inside, the view cuts to camera <to>. Only the zones of
//     the current camera are checked, exactly like RE1.
//
// start <id>
//     The camera used when the map begins.
//
// All positions are Doom map units (the floor is at height 0 everywhere).
//
// How these zones were chosen: a test measured, on a 32-unit grid, which
// cameras can see the player at every spot of every room. Each zone leads
// to a camera that sees that whole area. Where two cameras overlap, the zone
// that leads A -> B and the one that leads B -> A leave a small gap between
// them, so the view doesn't flicker when you stand on the border.
//
// Safety net (FixedCamera.zs): if the player is ever out of view for about
// 0.2 s anyway, the view cuts to whichever camera shows them best.
//
// Tip: type "re_debugcams 1" in the console to see each cut.
// ---------------------------------------------------------------------------
